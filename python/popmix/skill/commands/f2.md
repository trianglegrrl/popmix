# popmix f2

f2(A, B): the genetic drift between two populations, the mean squared
difference of their allele frequencies corrected for sampling bias, with a
block-jackknife standard error. Every other f-statistic is a sum of f2s.

## Synopsis

```text
popmix f2 --pop1 A --pop2 B (--input PREFIX | --f2-dir DIR) [options] [--format text|json|tsv]
```

## Arguments and options

| Option | Type | Default | Meaning |
|--------|------|---------|---------|
| `--pop1` | text | required | Population A. |
| `--pop2` | text | required | Population B. |
| `--input`, `-i` | text (path) | none | Genotype prefix. f2 blocks are extracted for exactly this command's populations, on the SNPs with data in all of them (with `--maxmiss 0`). Give this or `--f2-dir`. |
| `--f2-dir` | path (directory) | none | Read f2 blocks saved by [extract-f2](extract-f2.md) instead of genotypes; every population must be in them. The SNP set is the one extract-f2 chose. |
| `--block-size` | number | 0.05 | With `--input`: jackknife block length in Morgans. |
| `--maxmiss` | number (0 to 1) | 0 | With `--input`: keep SNPs missing in at most this fraction of the populations. |
| `--all-chromosomes` | flag | off | With `--input`: use every chromosome, not only autosomes 1-22. |
| `--pseudohaploid` | `detect`, `admixtools2`, `diploid` | `detect` | With `--input`: which samples count one allele per SNP (see [SKILL.md](../SKILL.md#things-every-command-shares); `admixtools2` reproduces ADMIXTOOLS2-0007). |
| `--format` | `text`, `json`, `tsv` | `text` | `json` holds `estimate`, `std_err`, `z_score`, `n_snps`; `tsv` one row with those columns. |

## Inputs and outputs

Genotypes (`--input`) or an f2 directory (`--f2-dir`); the result on stdout:

```text
f2(French, Yoruba):
  Estimate: 0.057354
  Std Error: 0.001608
  Z-score: 35.669
  N SNPs: 20881
```

## Examples

```bash
# runs
popmix f2 -i family --pop1 French --pop2 Yoruba
popmix f2 -i family --pop1 French --pop2 Simulation.1 --format json
popmix extract-f2 -i family -o f2_family --populations French,Yoruba,Simulation.1
popmix f2 --f2-dir f2_family --pop1 French --pop2 Yoruba --format tsv
```

```bash
# not run: needs the AADR
popmix f2 -i /references/aadr/v62.0_1240k_public --pop1 Han.DG --pop2 Yoruba.DG
```

## Reading the result

The estimate is in units of drift (0.057 between French and Yoruba here);
it is positive for distinct populations and near 0 for two samples of one
population. Z = estimate / SE;
`N SNPs` counts the SNPs used. FST is a ratio built from the same blocks
(Python `F2Blocks.fst`).

## Caveats

- With `--input`, the SNPs are those with data in both populations, so f2
  values of different pairs come from different SNP sets; use `--f2-dir` to
  compare pairs on one set.
- Text output rounds to 6 decimals; use `--format json` for full precision.

## Reference

admixtools2 `f2()` on `f2_from_geno()` blocks (2.0.10), rtol 1e-10, SE 1e-6.
