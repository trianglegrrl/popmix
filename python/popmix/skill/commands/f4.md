# popmix f4

f4(A, B; C, D) = (f2(A, D) + f2(B, C) - f2(A, C) - f2(B, D)) / 2: the
correlation of allele-frequency differences A-B and C-D. Zero (within
error) when (A, B) and (C, D) form a tree; non-zero means gene flow between
the branches (ABBA-BABA test).

## Synopsis

```text
popmix f4 --pop1 A --pop2 B --pop3 C --pop4 D (--input PREFIX | --f2-dir DIR) [options] [--format text|json|tsv]
```

## Arguments and options

| Option | Type | Default | Meaning |
|--------|------|---------|---------|
| `--pop1` | text | required | Population A. |
| `--pop2` | text | required | Population B. |
| `--pop3` | text | required | Population C. |
| `--pop4` | text | required | Population D. |
| `--input`, `-i` | text (path) | none | Genotype prefix. f2 blocks are extracted for exactly this command's populations, on the SNPs with data in all of them (with `--maxmiss 0`). Give this or `--f2-dir`. |
| `--f2-dir` | path (directory) | none | Read f2 blocks saved by [extract-f2](extract-f2.md) instead of genotypes; every population must be in them. The SNP set is the one extract-f2 chose. |
| `--block-size` | number | 0.05 | With `--input`: jackknife block length in Morgans. |
| `--maxmiss` | number (0 to 1) | 0 | With `--input`: keep SNPs missing in at most this fraction of the populations. |
| `--all-chromosomes` | flag | off | With `--input`: use every chromosome, not only autosomes 1-22. |
| `--pseudohaploid` | `detect`, `admixtools2`, `diploid` | `detect` | With `--input`: which samples count one allele per SNP (see [SKILL.md](../SKILL.md#things-every-command-shares); `admixtools2` reproduces ADMIXTOOLS2-0007). |
| `--format` | `text`, `json`, `tsv` | `text` | `json` holds `estimate`, `std_err`, `z_score`, `n_blocks`; `tsv` one row with the four populations and those columns. |

## Inputs and outputs

Genotypes or an f2 directory; the result on stdout:

```text
f4(Yoruba, French; Simulation, Simulation.1):
  Estimate: -0.002356
  Std Error: 0.002655
  Z-score: -0.888
  N blocks: 50
```

## Examples

```bash
# runs
popmix f4 -i family --pop1 Yoruba --pop2 French --pop3 Simulation --pop4 Simulation.1
popmix f4 -i family --pop1 Yoruba --pop2 Simulation.1 --pop3 French --pop4 Simulation --format tsv
```

```bash
# not run: needs the AADR
popmix f4 -i /references/aadr/v62.0_1240k_public \
  --pop1 Mbuti.DG --pop2 Han.DG --pop3 French.DG --pop4 Russia_Samara_EBA_Yamnaya
```

## Reading the result

|Z| > 3 is the usual threshold (the text output then adds `=> Significant
deviation from tree-like evolution`). With A an outgroup, f4(A, B; C, D) > 0
means B shares more drift (or gene flow) with D than with C, and < 0 with C.
Swapping C and D, or A and B, flips the sign.

## Caveats

- This is f4, not the normalized D-statistic; use [qpdstat](qpdstat.md)
  `--d-mode` (from genotypes) for D. f4 and D have the same sign and nearly
  the same Z.
- With `--input` the SNPs are those with data in all four populations.
- For many combinations use [qpdstat](qpdstat.md); for a matrix,
  [dstat-matrix](dstat-matrix.md).
