# popmix f3

f3(C; A, B) = (f2(C, A) + f2(C, B) - f2(A, B)) / 2, the admixture test of
Patterson et al. 2012: significantly negative f3 shows that C is a mixture
of populations related to A and B.

## Synopsis

```text
popmix f3 --target C --source1 A --source2 B (--input PREFIX | --f2-dir DIR) [options] [--format text|json|tsv]
```

## Arguments and options

| Option | Type | Default | Meaning |
|--------|------|---------|---------|
| `--target` | text | required | Population C, tested for admixture (the f3 "target", first position). |
| `--source1` | text | required | Population A, a proxy for one source. |
| `--source2` | text | required | Population B, a proxy for the other source. |
| `--input`, `-i` | text (path) | none | Genotype prefix. f2 blocks are extracted for exactly this command's populations, on the SNPs with data in all of them (with `--maxmiss 0`). Give this or `--f2-dir`. |
| `--f2-dir` | path (directory) | none | Read f2 blocks saved by [extract-f2](extract-f2.md) instead of genotypes; every population must be in them. The SNP set is the one extract-f2 chose. |
| `--block-size` | number | 0.05 | With `--input`: jackknife block length in Morgans. |
| `--maxmiss` | number (0 to 1) | 0 | With `--input`: keep SNPs missing in at most this fraction of the populations. |
| `--all-chromosomes` | flag | off | With `--input`: use every chromosome, not only autosomes 1-22. |
| `--pseudohaploid` | `detect`, `admixtools2`, `diploid` | `detect` | With `--input`: which samples count one allele per SNP (see [SKILL.md](../SKILL.md#things-every-command-shares); `admixtools2` reproduces ADMIXTOOLS2-0007). |
| `--format` | `text`, `json`, `tsv` | `text` | `json` holds `est`, `se`, `z`, `p`, `n_blocks` (z and p null without an SE); `tsv` one row with target, sources and those columns. |

## Inputs and outputs

Genotypes or an f2 directory; the result on stdout:

```text
f3(Simulation.1; French, Yoruba):
  Estimate: -0.008811
  Std Error: 0.000809
  Z-score: -10.885
  N blocks: 50
  => Significant admixture signal
```

## Examples

```bash
# runs
popmix f3 -i family --target Simulation.1 --source1 French --source2 Yoruba
popmix f3 -i family --target Simulation.1 --source1 French --source2 Yoruba --format json
```

```bash
# not run: needs the AADR
popmix f3 -i aadr_v66p1 --target Uygur.DG --source1 Han.DG --source2 French.DG
```

## Reading the result

A negative estimate with Z below -3 is evidence of admixture (the text
output then adds `=> Significant admixture signal`). A positive f3 does not
rule admixture out: drift in the target after the mixture can mask it.
`N blocks` is the number of jackknife blocks.

## Caveats

- A target of one pseudo-haploid sample has one allele per SNP: its
  sampling bias cannot be corrected, so f3 comes out too large (`qp3pop`
  on genotypes gives NaN). popmix warns, on f2 it extracted itself.
- This f3 is computed from f2 blocks, so it is not normalized by the
  target's heterozygosity. [qp3pop](qp3pop.md) with `--input` reports
  admixtools2's normalized f3 from genotypes; the sign is the same and Z similar (-10.9 here against
  -11.5), the values are not.
- For many targets or sources use [qp3pop](qp3pop.md).

## Reference
